# RAMESH & GRANDSONS — Website

This is a responsive static website for the RAMESH & GRANDSONS parent brand.

## Included
- Parent company/group presentation
- Ramesh Radio Center electronics vertical
- E-commerce section with Amazon link
- WhatsApp enquiry/order flow
- Product/category cards
- Three partner profiles with supplied photos
- Future ventures: Import/Export, IT/Services, Manufacturing, Trading
- Contact details and GSTIN
- Placeholder social-media section for future accounts

## Important before going live
1. The Meesho URL supplied was a seller-panel URL. Replace it with the **public Meesho storefront URL** once you have it.
2. Confirm the final legal/brand wording before publishing the GSTIN and business details publicly.
3. Replace the temporary Gmail address when the official domain email is ready.
4. Add real product photos, prices, SKU/product pages and stock data when ready.
5. Create real Instagram/Facebook/LinkedIn links before replacing the “Coming Soon” text.

## Deployment
Upload `index.html` and the `assets/` folder to any normal static hosting/server. The site does not require a database for the current version.

For a Linux/Nginx server, place the files under your web root and configure the domain's DNS A record to the server IP. Then enable HTTPS with your normal certificate setup.
